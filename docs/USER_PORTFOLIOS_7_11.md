## 实现与安全顺序

Account 所有者在 `data/account/unified/portfolio-control.db` 保存名称、来源、创建幂等键、执行绑定版本和最小删除标记。创建幂等预约先持久化；中断重试使用同一ID及已提交的原账本。启动迁移只登记原账户元数据，不写原账本或投影。12个退役账户有历史来源/必要证据，未完成逐个安全删除证明，本轮隔离保留。

Frozen Input 新增来源命名空间、绑定版本、账户业务状态版本及策略版本。版本不被行情估值刷新改变；风险设置/暂停使用新修订身份，恢复旧设置不复用旧资格。提交前再检查账户、绑定、模式、证据、状态、报价和幂等；旧冻结输入不被改写。账户上下文读取与绑定变更共用 Owner 顺序，不能冻结 A 的持仓与 B 的身份。

删除先在控制事务提交 DELETING 与解除绑定，阻止迟到写入；再在同一 Owner 写入栅栏校验已关闭的账户SQLite和白名单文件，永久删除独有目录，最后DELETED。中断重试幂等；未知文件、链接或占用会保守停在DELETING，不动共享行情、Opinion或通知。无备份。所有账户Repository事务共用控制栅栏，AI网络调用不持有它。HTTP同源限制不变。

已有真实模式未改变。手动立即分析一直与自动实时分析使用相同账户执行模式，本轮只明确显示此语义；Telegram允许手动通知没有增加交易授权。历史分析仍无Account写端口。

最近建议摘要由Account保存小型自包含说明（计划、结果与原因），不复制市场输入；账户自身执行历史及必要证据仍保留。目录列表仅读元数据，不遍历全部账本；只读取所选账户，页面显示最近30项。

## 用户操作

Account → 新建：填写名称、本金和必要风控，默认只给建议。保存后到 Live → 当前执行账户，显式选择资金池。Account切换查看不会改变它。
Account → 账户设置：修改名称/风险/执行模式；本金创建后不可编辑。
Account顶部 → 暂停新增风险/恢复；Live摘要读取同一状态。
Account → 删除：一次不可恢复确认，解除Live绑定并删除该账户独有数据；本轮没有删除正式账户。
